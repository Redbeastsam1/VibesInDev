# VibesInDev (Fabric Client Mod)

The official Fabric client companion mod for **VibesInDev** servers.

## Features

- **Direct In-Game Streaming**: High-quality Vorbis audio streamed over standard Minecraft packet channels.
- **Zero Port Forwarding**: No external web servers, VoiceChat plugins, or HTTP ports needed.
- **Synced Playback**: Position and volume stay synchronized with the server and other players.
- **Gapless Preloading**: Smooth transitions between songs with lookahead preloading.
- **Zero Resource Pack Required**: Audio plays directly without storing clutter on your local disk.

## Requirements

- Minecraft `26.3`
- Fabric Loader `>=0.19.5`
- Fabric API

## Installation

1. Install [Fabric Loader](https://fabricmc.net/) for Minecraft `26.3`.
2. Place `fabric-api.jar` and `vibesindev-1.0.0.jar` into your `.minecraft/mods` directory.
3. Join any Minecraft server running the companion VibesInDev plugin.

## In-Game Controls & Commands

- `/music volume <0-100>`: Set your music volume.
- `/music np`: Open the Now Playing interactive menu.
- `/music like` / `/music dislike`: Provide feedback on the active song.
